## 🌟 核心特色与功能亮点

### 1. 沉浸式拼写与智能防干扰
- **键盘盲打与卡片互选双模**：支持物理键盘盲打拼写与点击选词卡片双交互。
- **打字自动隐藏选词卡**：开始打字时自动平滑淡出下方选词区，避免视线干扰与过度提示依赖；按下 `H` 键或点击按钮随时唤出提示。
- **即时纠错与进度反馈**：拼写字母实时变色校验，音效实时反馈。

### 2. 深度句法成分分析与全中文详解（深度对标句乐部）
- **可视化成分胶囊**：主语、谓语、宾语、定语、状语、表语等多色语法药丸标签。
- **100% 中文翻译与词性标注**：卡片单词下方完整呈现地道中文含义与词性。
- **跟随居中与全中文详解**：
  - 点击或聚焦单词，单词卡片**平滑滚动居中**，详解面板始终稳定在视口中央。
  - 提供**全中文语法剖析、用法要点、双语发音例句**。
  - 拓展**词族派生链、近义/反义词对比、高频短语搭配**。

### 3. 动态「串记 · 联想 · 扩展」智能卡片
- **词族串记**：提炼句子核心词的衍生词链（如 `care → careful → carefully → careless`）。
- **主题联想**：智能推荐与本句情境高度相关的 3~5 个联想词汇。
- **拓展搭配**：核心短语固定搭配，每条配备中英双语地道例句，支持一键真人质感发音。

### 4. 丰富的三级架构课程包商城（商城 → 课程包 → 章节 → 逐句练习）
- **9 大精品分类**：
  1. **推荐**：热门榜、本周新课、编辑精选、流行文化
  2. **教材同步**：人教版、外研版、牛津版、新概念英语全套 (1~4册)
  3. **考试备考**：中考、高考、大学英语四级、六级、考研、雅思口语、托福核心
  4. **少儿英语**：字母启蒙、自然拼读、童话寓言、亲子互动
  5. **基础学习**：音标速通、高频1000词、核心句型、基础语法
  6. **场景英语**：机场出行、酒店入住、餐饮就餐、商务会议、职场面试、旅行问路
  7. **阅读听力**：短篇故事、经典演讲、名人名言、新闻选读
  8. **影视英语**：老友记口语、生活大爆炸、漫威经典台词、好莱坞大片名场面
  9. **音乐英语**：欧美经典流行金曲歌词学语法
- **海量真实地道语料**：所有课程包均配有多章节真实语料库，拒绝占位假数据。

### 5. 全方位多模态练习支持
- **中译英拼写**：看中文打英文，训练快速造句思维。
- **听写模式**：隐藏英文字符，盲听发音拼写，锻炼听觉敏锐度。
- **听力精听磨耳朵**：支持单句精听、循环复读、慢速 0.75x/1.0x/1.25x 播放。
- **口语跟读与智能评测**：内置浏览器语音识别引擎，实时打分。
- **篇章连贯阅读模式**：支持段落级沉浸阅读与逐句点读。
- **生词本与错题自动归纳**：做错的句子一键收录，针对性攻克难关。

## 🛠 本地开发与运行

```bash
# 1. 克隆代码仓库
git clone https://github.com/wqh001-edu/sentence-master.git
cd sentence-master

# 2. 安装项目依赖
npm install

# 3. 启动本地开发服务器
npm run dev

# 4. 构建生产环境产物
npm run build
```
